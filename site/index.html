352 frames, nine critics

One Claude Code session took a 14.7-second promo for an AI agent app called Runner and rebuilt it frame for frame as a web page that draws itself, set to the exact original soundtrack. Three rounds of AI critics measured it against the original until the user called it done. Above is the whole session, rendered from its transcript. Below are the videos, the numbers, and every prompt the user typed with what Claude did in response.

The original and the recreation

Both use the same mp3, so the original plays muted.

Critic scores by round

Nine Opus 5.5 critics, three per round, each owning one overlapping slice of the video and scoring it out of 10. Every round used fresh critics on the latest render.

Similarity to the original

Mean SSIM over all 352 frames after each scored render, where 1.0 is identical. Claude's score.sh also printed SSIM per second, which is how it caught a regression in the click section.
